## 2. 门禁脚本

| 门禁 | 脚本 | 产出 |
| --- | --- | --- |
| 代码（测试 + clippy + 构建 + 签名） | `tools/run_gate.sh` | 摘要 + `/tmp/coffer-gate-*.log` |
| UI（L1/L2/L3） | `tools/run_ui_gate.sh` | 摘要 + 日志 |
| 发版前检查 | `tools/run_release_checklist.sh <tag>` | PASS/WARN/FAIL + 日志 |

门禁由非作者执行；结论附日志路径与退出码。

## 3. 红线

- **R2 零泄漏**：密码值绝不进入 LLM 上下文；测试密码只经 `COFFER_TEST_PASSWORD`；实样文件只读首行列头，绝不读取数据行；明文导出用后立即删除。
- **私钥纪律**：`UPDATE_SIGNING_KEY_BASE64` 只经环境变量传递，不打印、不落盘；只允许输出派生公钥。
- **Git 纪律**：commit 一律 pathspec，严禁 `git add -A` / `git add .`；本仓 commit 不加 `Co-Authored-By`（用户 2026-10-10 裁定）。
- **共享工作树**：存在并行会话改动时，只提交本任务文件；amend 前确认顶 commit 归属。
- **cargo 门禁**：`PATH="$HOME/.cargo/bin:$PATH"` 前插，保留原 PATH。
- **零网络**：除 OTA 的 `network.client` 最小豁免外，不得新增网络能力。

## 4. 项目内角色约定

- dev-integrator：由 dev-architect 兼任，负责多 coder 合并后的接口一致性与回归编排；不代替 dev-tester 执行回归。
- 设计走查：ui-reviewer 在设计交付后、发版前对实现做一次走查，产出 PASS 或偏差清单。
