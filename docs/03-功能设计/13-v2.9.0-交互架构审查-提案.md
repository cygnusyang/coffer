## 1. 现状信息架构（审查时点快照）

```
Coffer（窗口：WindowGroup "Coffer"，min 820×540，关窗驻留菜单栏）
├─ 主窗口 RootView（按 AppPhase 切换）
│   ├─ .booting        → ProgressView「正在打开…」
│   ├─ .noVault        → VaultSetupView（建库：名称+主密码+确认+强度条）
│   ├─ .locked         → LockView（主密码 / Touch ID / 忘记主密码→RecoveryResetSheet / 退避倒计时）
│   ├─ .unlocked       → MainView（NavigationSplitView 三栏）
│   │   ├─ 侧栏 sidebar（全部条目/收藏/类别…/回收站/安全体检）
│   │   ├─ 中列 middleColumn（trash→TrashListView；health→HealthCheckView 整页；其余→ActiveItemList）
│   │   └─ 详情 detailPane（无选中占位 / ItemDetailView：字段/URL/标签/TOTP/Passkey/历史/附件）
│   ├─ 覆盖层 sheets（Root：bio 引导/恢复码引导/库切换/OTA；Main：新建/导入×4/导出；
│   │   ItemDetail：编辑/更新密码/跨库复制/历史/大字号；ItemEdit：TotpScanView）
├─ 设置窗口（独立 Window id "settings"，v2.4.1 由 sheet 改独立窗口，无 phase 门控 ← FW-02）
│   └─ SettingsView：9 节 × 7 sheet 堆叠（通用/剪贴板/备份/生成器/安全/数据/诊断/许可/MCP）
└─ 菜单栏 StatusItem（状态行 / 打开主窗口 / 快速搜索 ⌥⌘P / 锁定全部 / 退出）
```

结构性观察：主窗口三栏符合 macOS 密码管理器惯例（与 Apple Passwords.app 侧栏分类行模式一致）；主要结构噪音为①健康体检整页借位中列 filter（IA-05）、②四个导入向导同壳复制（IA-03）、③设置窗口 9 节×7 sheet 堆叠导航三级深（IA-01）。

## 4. 竞品/平台基线（ui-research 摘要）

> 全表与出处见 /tmp/coffer-ia-review/research-baseline.md 的归档要点（下述为结论级摘要）。取证：Apple HIG 直读 + 竞品官方文档/Wayback/DDG；1P8 编辑模态细节未取证已标 `[推测]`。

1. **侧栏分类**：1P8/Bitwarden 下拉化（1P8 有用户抱怨），Apple Passwords.app 用侧栏分类行——Coffer 现状与平台原生基准一致，**保留侧栏分类行，明确不跟下拉化**。
2. **全局快速搜索**：1P8 Quick Access（⇧⌘Space 浮层）/ Raycast 命令面板值得评估；Coffer 现状 ⌥⌘P 聚焦主窗口搜索框。**登记为评估项**（见 §5 裁定 4），非本轮提案。
3. **锁定模型**：三竞品锁定均全局可触达；Coffer 覆盖已全（工具栏+菜单栏+AutoLockMonitor），**唯一缺项=锁定快捷键**（P7 收口）。
4. **HIG 模态梯度**：就地编辑（简单可逆）→ sheet（简短聚焦）→ 独立窗口（长时/复杂/参照）。**Coffer 编辑是固定 560×560 多步模态 sheet，与 HIG「sheet 只放简短聚焦任务」存在张力**——见 §5 裁定 3。
5. **设置组织**：HIG 建议 pane ≤ 5 的侧栏式 Settings；Coffer v2.4.1 已独立窗口但仍是 9 节单长滚动——与 IA-01 同根，**值得评估拆侧栏 pane**（对齐其本来的「系统设置样式」目标）。
6. **其余**：⌘Z Undo 成本低可补（SwiftUI 文本控件默认支持）；Raycast 式 alias/frecency **明确不跟**（定位不符）；菜单栏常驻**已覆盖无需新增**。

风险口径：今日 WebSearch 后端 403、1Password support 域 CloudFront 封禁（改 Wayback+DDG 兜底）；HIG menu-bars/keyboard-shortcuts 两页 404，⌘F/⌘N 等标准键标 `[推测惯例]`（以 Bitwarden 实测映射佐证）。

## 5. Lead 裁定（4 条）
