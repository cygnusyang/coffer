## §1 背景与目标

- **反馈**：用户对菜单栏挂锁图标不满，原话「锁的头部（锁梁）太长，不美观」，要求提高审美。

- **目标**：把锁梁从「高窄圆拱」改为「短扁敦实」的 SF Symbols 式挂锁比例；锁/解锁双态保持一眼可辨；不改变绘制框架、状态机与菜单结构（纯参数 + 锁梁路径结构的参数级修订）。
- **版本归属**：品牌图标重绘，无 FFI/状态机改动，属低风险 UI 修订，版本归属由 lead 裁定（候选 v2.10.0 快赢槽）。

## §2 现状问题诊断

### 2.1 现状几何（`icon(phase:)` 参数，glyph = 14pt）

| 参数 | 现值（×glyph，glyph=14pt） | 绝对尺寸 |
|---|---|---|
| glyphInset | 2pt（画布 18pt → 图形区 14×14） | 不变 |
| 锁体宽 | 0.64 | 8.96pt |
| 锁体高 | 0.52 | 7.28pt |
| 锁体圆角 | 0.12×体宽 | ≈1.08pt |
| 锁梁线宽 | 0.15 | 2.1pt |
| 锁梁弧半径（圆） | 0.22 | 3.08pt |
| 弧顶距 glyph 顶 | 0.02 | 弧顶路径 y≈15.72 |
| 锁态腿沉入锁体 | 0.11 | 1.54pt |
| 解锁态旋转 | 40°（y-up 逆时针） | — |

### 2.2 本机实测（锁态，4x 位图剖面；墨迹口径含圆帽，定义见 §3.3）

| 指标（墨迹口径） | 现状 | SF Symbols `lock.fill` @18 |
|---|---|---|
| 整体宽/高（锁体宽/墨迹总高） | **0.61**（窄高） | **0.81**（方正） |
| 锁体高 / 总高 | 0.49 | 0.60 |
| 锁梁可见高 / 总高 | **0.51** | **0.42** |
| 锁梁可见高 / 锁体高 | **1.03**（头 = 身） | **0.70** |
| 锁梁高 / 锁体宽 | **0.83**（瘦高头） | **0.52** |

### 2.3 根因（为什么「头太长」）

1. **锁梁是「高窄半圆」**：`arcRadius = 0.22×glyph` 决定两腿只张开 0.44×glyph 宽；弧顶又贴到 glyph 顶（留 0.02）。几何上这是**瘦高圆拱**，不是扁圆弧——读起来像高帽，不像短锁梁。
2. **锁梁与锁体等高**：锁梁可见高（墨迹含帽，弧顶→体顶）≈7.5pt，锁体高 7.28pt，**1.03:1**。SF 是 0.70:1，头部应明显矮于身体。
3. **整锁偏窄**：锁体 0.64×glyph 宽 + 头部 0.44×glyph 宽，整体 w/h 0.61，比 SF（0.81）窄一截，显得细长。
4. **弧顶墨迹越出字形区上界**：圆帽顶点 16.77pt，越出字形区上界（16.0）约 0.77pt，顶边发虚（仍在 18pt 画布内，非裁切）。

> 结论：**问题不在锁梁「该多高」，而在「锁梁的形状与占比」**——要短扁敦实，必须做两件事：① 锁梁从圆形半圆改成**扁椭圆弧 + 短竖直腿**（SF 式平顶拱）；② 锁梁高度压到锁体的 0.6~0.7 倍，同时把锁体/整锁做宽。

### 3.2 SF Symbols `lock` / `lock.fill`（16–18pt 渲染量测）

本机 AppKit 量测 `lock`/`lock.fill` @16/@18（4x 位图剖面），轮廓两版一致（fill 为实心版，便于结构读取）：

| 指标（@18） | `lock.fill` 实测 |
|---|---|
| 墨迹 bbox | 12.5 × 15.5pt，w/h = **0.81** |
| 锁体 | 12.5 × 9.25pt（体高/总高 = 0.60） |
| 锁梁可见高 | 6.5pt（梁/体 = **0.70**，梁高/体宽 = 0.52） |
| 锁梁顶部 | **扁穹顶**：顶 3 行即大幅变宽，随即分叉为两条腿；非圆拱 |
| 双腿 | 短竖直段（体顶上方约 1.5–2pt）后接弧；腿厚≈2–3pt；腿间缝≈1.5–3.5pt |
| 梁外宽/体宽 | 0.76（fill；outline 版 1.00）——锁梁不宽于锁体 |

> **可迁移的比例语言**：① 锁梁「矮于锁体」（梁/体 0.7）；② 锁梁顶部是**扁穹顶**（宽/高 ≈ 1.5–2:1），不是半圆；③ 锁梁腿短、贴体；④ 整锁方正（w/h ≈ 0.8）。

### 3.3 量测口径（自证，脚本 /tmp/coffer-menuicon，不入仓）

- 渲染：NSBitmapImageRep 4x 背板（`rep.size` = 18pt / 72px），`imageInterpolation = .none`，逐像素读 alpha（阈值 24/255）。
- 结构行剖面：每行不透明段数 → 弧区（1 段）/ 腿区（2 段）/ 锁体（1 段实心）；锁梁可见高 = 顶细条行 → 锁体顶行的距离；梁/体 = 锁梁可见高 / 锁体高。
- SF 符号以 `pointSize` 渲染后量墨迹 bbox 归一；本文对比一律用「÷各自墨迹总高」的相对值，尺寸无关。

> **双口径定义（MEDIUM-1）**：
> - **路径口径**（实现可测目标，code 可断言）：纯几何参数。梁/体 = (竖直腿 + 穹高) / 锁体设计高 = 5.04 / 7.56 = **0.67**（现状 1.00）。
> - **墨迹口径**（真机比对，渲染实测含圆帽）：梁/体 = (墨迹顶→锁体顶) / 锁体设计高 = (15.65 − 9.56) / 7.56 = **≈0.81**（现状 1.03，SF 0.70）；整体 w/h = 锁体设计宽 / 墨迹总高 = 10.08 / 13.65 = **≈0.74**（现状 0.61，SF 0.81）。
> - 两者关系：墨迹梁高 = 路径梁高 + 圆帽凸出（线宽/2 = 1.05pt），故墨迹梁/体 恒大于 路径梁/体。全文数值一律标注口径，不混用。

## §5 双态绘制说明（实现契约，改 `icon(phase:)`）

### 5.1 锁梁路径结构（替换原 `appendArc` 圆形弧）

锁梁 = 竖直左腿 + 顶部**椭圆上半弧**（两段三次贝塞尔近似）+ 竖直右腿，开放路径、圆头线帽、圆角线接（均维持现状）：

```
// y-up；midX = 9.0（画布中点）；bodyTopY = glyph.minY + 体高（≈9.56）
lineWidth = glyph.height * 0.15          // 2.1pt
rx        = glyph.width * 0.20           // 2.80pt  椭圆水平半轴
ry        = glyph.height * 0.26          // 3.64pt  椭圆垂直半轴（穹高）
legTopY   = bodyTopY + glyph.height * 0.10   // 竖直腿上端（≈10.96）
legBottomY = 锁态: bodyTopY − glyph.height*0.10   /   解锁态: bodyTopY
k = 0.5523                               // 椭圆 1/4 弧三次贝塞尔近似系数

path.move(to: (midX − rx, legBottomY))                 // 左腿底（锁态沉入体、解锁态贴体顶）
path.line(to: (midX − rx, legTopY))                    // 左竖直腿
path.curve(to: (midX, legTopY + ry),
           controlPoint1: (midX − rx, legTopY + k·ry),
           controlPoint2: (midX − k·rx, legTopY + ry)) // 左上 1/4 椭圆弧 → 穹顶
path.curve(to: (midX + rx, legTopY),
           controlPoint1: (midX + k·rx, legTopY + ry),
           controlPoint2: (midX + rx, legTopY + k·ry)) // 右上 1/4 椭圆弧 → 右腿顶
path.line(to: (midX + rx, legBottomY))                 // 右竖直腿
```

> 说明：AppKit `NSBezierPath.appendArc(withCenter:radius:)` 只有圆弧。扁穹需椭圆弧，**用两段三次贝塞尔近似椭圆上半**（k=0.5523 为椭圆弧标准近似系数，对角点按各自半轴缩放）。顶点处切线水平（平顶）、腿端处切线竖直（腿垂直下落）——这正是 SF 穹顶的几何特征，圆形弧做不到（圆形弧腿端必然外撇）。
> 锁态先画锁梁再画锁体填充：腿端沉入体顶 1.40pt 被实心锁体覆盖，圆帽不外露。绘制顺序维持现状。

### 5.3 解锁态（unlocked）

- 锁梁整体绕左腿底端（锚点 = `(midX − rx, bodyTopY)`，即锁体顶边左腿处）逆时针旋转 **40°**（y-up 正角 = 逆时针，右腿上抬——机制维持现状）。
- 旋转后右腿路径端抬离锁体顶边：`2 × rx × sin40° = 3.60pt = 0.257×glyph`（现状 0.28×glyph），**高于 0.18×glyph 硬阈值**；含圆帽视觉 ≈0.33×glyph，悬空一目可辨。穹顶路径顶点抬至左上（y-up ≈15.2pt，y-down ≈2.8pt），**画布内无裁切**（墨迹顶 ≈16.8pt，18pt 画布余 1.2pt；相对字形区上界的越界见下注）。

> **解锁态墨迹越出字形区上界（MEDIUM-2，接受项）**：旋转 40° 后，穹顶曲线的最高点不是顶点端点，而是曲线中段某点（解析 max-y 路径 15.75 + 圆帽 1.05 = **≈16.8pt**，4x 实测 16.75–17.0），越出字形区上界（16.0）约 **0.8pt ≈ 1px@1x**。**归零两径均不可行**：① 压 `ry` 至 2.30pt（−37%）才可把越界压到 ≤0，墨迹梁/体 0.81 → 0.63（劣化 0.18，远超评审 0.03 阈值）；② 把旋转角降至 ≤9° 亦可归零，但右腿抬离降至 0.062×glyph，远低于 0.18 硬阈值、双态难辨。故按评审预案走**接受 + 兜底**路径：越界量与现状先例同级（生产图标锁态帽顶本已越字形区上界 0.77pt 且已发版无碍），§8.4 真机复核，观感发虚再单点微调。

## §6 1x 与深浅色自证说明

### 6.1 1x（18pt @1x = 18px 画布）可读性

> 本节只引用**计算值 / 4x 剖面值**（§3.3 口径）；§5 的 1x 像素图为示意（每字符 = 1px，非矢量精确），数字以本节为准（M-4 修正）。

- 锁体：10.08 × 7.56pt → **10 × 7–8px** 实心大色块。
- 锁梁：描边 2.1pt → **2px**；穹外宽 7.7pt → **~8px**，穹高 5.04pt → **~5px**。拱顶处两腿描边合拢成小实顶（墨迹约 2–3px 厚），随即分叉为两腿。
- 腿缝：中心距 5.6pt − 描边 2.1pt = **3.5pt → ~3px**（含抗锯齿视觉约 3–4px）。
- 腿厚：2.1pt → **2px**。**关键特征均 ≥1.5px**（腿厚 2px、腿缝 ~3px 均 > 1px 分辨阈）。
- 双态可辨（§5 像素图）：锁态平顶细拱 + 实心体；解锁态斜拱、右腿端与体顶之间可见空隙（抬离 3.6pt ≈ 3–4px）。
- 穹顶顶点处两腿描边自然合拢（拱顶收拢），非依赖细线——与 SF 一致，非缺陷。

### 6.2 深浅色（template 视觉重量）

- 图标为 black+alpha template，`isTemplate = true`，由系统按深浅色渲染填充色。**规格不分色**。
- 视觉重量（墨迹覆盖面积）在两底不变：锁梁线宽 2.1pt、锁体实心，深浅色下占比一致。相对现状整体墨迹约 +8%（主要来自锁体加宽），属可接受范围内，且与 SF（更致密）方向一致。
- 对比度由系统 template 渲染保证（菜单栏图标规范），本项目不额外干预。

## §8 遗留视觉未决项（诚实边界）

1. **版本归属**：本修订是否入 v2.10.0 快赢槽、还是独立版本，由 lead 裁定（本文默认 v2.10.0 候选）。
2. **SF 参考的「梁/体」取值（墨迹口径理由句）**：定稿**路径口径 0.67**（实现可测目标 = 5.04/7.56），对应**墨迹口径 ≈0.81**（真机比对 = 6.09/7.56，较旧版墨迹 1.03 缩短约 21%）。墨迹口径比 SF 0.70 略高的部分，来自描边圆帽在拱顶的固有上凸（stroked-U 必带，非设计意图）；路径口径则贴合 SF 0.70 的比例语言。若用户后续反馈「还想更扁」，可把 `shackleRy` 0.26 → 0.24 微调（路径 0.67 → 0.62，墨迹 0.81 → 0.77），锁体高不变即可，无需动结构。
3. **16pt 缩放档**：本规格以 18pt 画布为基准（现状即 18pt）。若未来出现 16pt 使用场景，系数不变、整体等比，1x 特征仍 ≥1.5px；暂不单列 16pt 档。
4. **真机观感复核（MEDIUM-2 兜底）**：最终以用户真机菜单栏观感为准（深浅色各看一次）。解锁态墨迹越字形区上界 ~0.8pt（≈1px@1x）为本版**接受项**——与现状先例（生产锁态帽顶越界 0.77pt）同级；若真机观感顶边发虚，可把 `shackleRy` 0.26 → 0.24（墨迹 0.81 → 0.77，解锁越界 0.8 → **≈0.62pt**——ry=3.36 时解析 max-y=15.573 + 帽 = 16.623），或 `rx` 各 ±0.02 微调，单点微调不重走评审。**禁止**为归零越界而把解锁旋转角降到 40° 以下（会击穿 0.18×glyph 抬离阈值）。
   - 归零第三径（已知选项，不采用）：整锁整体下移 δ∈[0.80, 1.08]pt——δ=1.0 时墨迹顶 15.80、抬离 0.186×glyph 仍 >0.18 阈值；可行但抬离余量压至临界（0.186 距 0.18 仅 0.006×glyph）、解锁腿端相对字形区下潜约 1px 且锁体底贴近字形区下界，取舍不及「接受 + 兜底」，记为已知选项。
5. **实现回归点（LOW-2）**：`0.18×glyph` 抬离阈值目前仅是注释纪律、**无测试**。实现时由 dev-team 新增几何断言——由锁梁路径参数推导抬离值并断言 ≥ 0.18×glyph（新值 0.257×glyph 仍通过）；并可另断言路径口径梁/体 ≤ 0.7（新值 0.67 通过）。
