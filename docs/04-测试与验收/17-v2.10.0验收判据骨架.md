## §0 范围与总开关

- **本版定位**：v2.10.0（D1）= docs/03-功能设计/16-库删除设计.md r0.4 的库删除能力收口——**三入口**（设置「数据」区「管理密码库…」主入口 + 库切换 sheet 底部深链 + LockView「忘记主密码？」工厂级入口）→ **VaultManagementView**（列全库，行内 `[删除…]`）→ **DeleteVaultConfirmSheet** 多步向导（Step1 目标与方式双选 → Step2 [先导出再删：C8 参数化导出步] → Step3 输入库名逐字符确认 → Step4 执行 → Step5 完成反馈与落位）。
- **硬约束（违反即打回，判据不得放宽）**：
  - 确认门 = **仅输入库名逐字符确认，无任何密码步**（UDR-3 采纳，§3.4 理由重构）；**比对前双方 trim**（UDR-1 必改，Swift 侧）；同名库 Step3 尾显 masked UUID（UDR-7）；
  - 删除操作**工厂级**（无解锁会话依赖、无密码门，与 restore 同构）；锁定态/忘密废库均可删；
  - **当前库可删**（先锁旧再删）；落位 = 多库切 createdAt 最近者 `.locked` / 单库 `.noVault`，**删除后不自动解锁**；
  - 导出前置步 C8 **必落（非可选项，S-6）**：ExportView 参数化 targetVaultDir/targetVaultName + 全目标仅加密备份 + 显式展示目标库；「先导出再删除」路径导出成功才放行 Step3（强制保数据）；
  - CLI 删除命令**不新增**（六裁定 #6）。
- **回退/归属边界（判据依赖实现决策，不预置 pass/fail）**：core 库名校验（禁首尾空白/长度上限）为「若并入」判据（§7），不并入则 Swift trim 兜底仍满足删除确认；LockView 工厂级入口真机可达性待实现轮验证（附 C）。
- **诚实边界**：Swift/UI 侧无自动门禁 → 标「真机」判据为人工核销项（§9 集中清单）；可自动化面 = Rust 内核（C1/C3、许可门禁）+ Swift 纯函数 scratch（C8 参数化、trim 比对、落位选择、Keychain 幂等）；**未实现不标 ✅**。
