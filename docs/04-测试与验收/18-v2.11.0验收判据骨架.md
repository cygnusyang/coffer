## 3. core 侧用例明细（先红后绿全闭环 `tests/dropzone_import.rs`，18 例 / 18 绿）

> 目标契约：`cf_importer::dropzone::{analyze_dropzone, import_dropzone, DedupCategory, DropzoneAnalysis, DropzoneRow}`（docs/21a §1.4，lead 冻结）。
> **G1 契约要求**：`DropzoneRow`/`DropzoneAnalysis` 字段与 `DedupCategory` 变体须 `pub` 且可 `Debug`；`DropzoneAnalysis.rows` 顺序 = 文件行序。集成测试对 `DropzoneAnalysis` 不含 `is_empty_vault`（该字段落 FFI 层 `FfiDropzonePrecheck`，docs/21a §1.5）。

| 用例 | 关联判据 | 输入/场景 | 预期（断言） |
|---|---|---|---|
| 空库全新增 | P-4 | 空库 + 2 条全新增 CSV | `new_count=2`，duplicate/conflict=0，`total_rows=valid_rows=rows.len()=2`，行序 ["new","new"] |
| 三元组匹配归重复且密码不作键 | P-4/S-3 | 种子 (GitHub,octocat,github.com) + 候选同三元组**不同密码** | Duplicate=1；密码不同不改变分类（元数据级去重已知限制） |
| URL 规范化归一归重复 | P-4/U-3 | 种子 `https://github.com` + 候选 `HTTPS://GitHub.COM/` | 规范化后一致 → Duplicate（大小写/协议/尾斜杠不敏感） |

| 混合分类计数与行序 | P-4 | 3 行混合（重复/新增/冲突） | 计数 1/1/1，行序 ["duplicate","new","conflict"]；行元数据 title/username/url 可读；**DropzoneRow 无 password 字段**（类型层 R2） |
| total含全空行valid仅非空 | P-4 | 含全空数据行 | `total_rows` 含全空行、`valid_rows`/`rows` 不含；数据首行 `line_no=2`（表头=1） |
| 无可识别表头整文件拒绝 | P-1 | `foo,bar` 表头 | `CfError::ImportUnknownFormat` |
| 非utf8报错 | P-1 | 非 UTF-8 字节 | Err（不 panic、不落库） |
| 文件内重名入告警 | P-4 | 同 CSV 内两行同 Title | 不拦截，`warnings` 含重名提示（docs/07 §3.2「全部新建」语义） |
| 选择集子集导入 | P-3/P-4 | 4 行 CSV + include=[3,5] | `imported_rows=2`；落库仅 B(line3)/D(line5) |
| 全选导入与预检行序一致 | P-3/P-4 | include=全行号集 | 报告所见=导入所得；`imported_rows=2` |
| 空选择集零导入 | P-4 | include=[] | 0 行导入、库零变化（「导入 N 条」N=0 disabled 的 core 面安全） |
| 文件漂移单事务零落库 | P-3 | 预检后删行改文件，include 含缺失行号 | `CfError::ImportFailed` + **库零落库**（fail-closed on drift） |
