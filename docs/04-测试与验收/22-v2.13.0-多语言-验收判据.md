## §0 范围与不变量

**本版一行意图**：中文保持为源语言与兜底语言（源码原文当 key，只发 `en.lproj`），英文作为增量译文覆盖全界面；错误文案由「码 + 原始载荷」改为「码优先，载荷降日志」。

**非目标（判据不得据此判红）**：

- 不建 `zh-Hans.lproj`；不声明 `CFBundleLocalizations`；`CFBundleDevelopmentRegion` 保持 `zh_CN`（D-7 方案 A）。
- 不把 `Text("中文")` 改成符号 key；不改 Rust 核心与 FFI 契约（D-6 方案 A / §7.2 方案 B 被否）。
- 不翻 Help Center 长文、CLI / MCP 协议输出、Rust 日志、三个 helper bundle、App Store 元数据与 docs。
- 不做复数（`.stringsdict`）、不做单位/日期本地化、不做「切换后自动重启」。
- 不要求 AX 能证明「无视觉截断」（做不到，见导读②）。

**必须保持不变的不变量**（任一被破坏即判红，即使「英文都翻了」）：

| ID | 不变量 | 依据 |
|---|---|---|
| INV-L1 | **中文界面逐字不回归**：源码 CJK 字面量集合只增不减，删除项必须落在白名单（分叉键、D-10 错误码文案、拼接串重构），且白名单逐条可读（TC-11） | 设计 §4.2 / AC-L10N-05 |
| INV-L2 | **en 分片的 value 不含 CJK**（出现即「译文没翻」，最硬的静态红线） | 本文件判据 |
| INV-L3 | **键 = 源码原文逐字节相等**（含标点、空格、全角括号）；插值形态按 F7 推导占位符；含插值时裸 `%` 转义为 `%%` | 设计 §5.1 |
| INV-L4 | **不存在键级跨语言回退**：所选 .lproj 缺 key → 回落 key 本身；**不得**实现「查 en 失败再查 zh」 | 设计 §6.5 / F2 |

| INV-L7 | **既有测试零删除、零放宽**：断言中文的既有用例必须全绿且计数不减（standalone 二进制无 bundle → 仍返回中文原文） | AC-L10N-10 |

## §1 先红基线与红→绿纪律

### 1.1 起草时的红形态（诚实说明，本机 2026-10-24 只读实测）

| 红形态 | 命中用例 | 说明 |

| **脚本缺失红**（`check_l10n.sh: No such file`，exit 127）→ **已失效** | 53–64 | 起草时门禁脚本未创建；现脚本已落盘并在**空/半成品分片**上 exit 0（实测，见 §18）。**当前红点从「脚本不存在」变为「译文未落盘」**：G6 覆盖率 3.5%，故 01/02 仍红，而 53–64 必须在注入副本上跑才红 |
| **编译级红**（符号不存在） | 44–52 | `CoreErrorText` / 映射表未创建 |
| **编译级红** | 23–31 | `LanguagePreference` / 语言行组件未创建 |
| **编译级红** | 32–33 | 宽度探针需从 en 表读「最长译文」，en 表为空时无从取值 |
| **可立即红的（真行为级）** | **03、04、09、10** | 见下：这几族**今天就能红**，因为缺陷已在现网代码里，与实现是否落地无关 |

**可立即红的证据（本机实测，`grep` 可复现）**：

1. **表达式形态字面量不查表**：`Text(` 入参是三元表达式时，Swift 选中 `Text(StringProtocol)` 重载而非 `LocalizedStringKey` → **永不查表**。本机命中 **12 处**（`SettingsView.swift:135/159/178`、`VaultSetupView.swift:39`、`ItemEditView.swift:248/641`、`RecoveryCodeSetupSheet.swift:188`、`LockView.swift:51`、`ExportView.swift:161`、`GeneratorSettingsView.swift:182`、`VaultSwitcherView.swift:32`、`DropzoneImportView.swift:551`）。这 12 处**不影响静态抽取的成功**（抽取看字面量，字面量确实在源码里），却必然在 en 界面留下中文 → **静态覆盖率会假绿**。→ TC-03、TC-05~08。
2. **`Text(verbatim:)` 的文案骨架**：设计 §9 AC-L10N-14 假定「11 处 verbatim 全部是数据/非语言」。实测 11 处中 **4 处是「文案骨架 + 数据」**：`TotpScanView.swift:145/146/147`（"发行方：\(issuer)" / "账户：\(account)" / "位数：\(digits) 位 · 周期：\(period) 秒"）、`ItemEditView.swift:190`（"已有 TOTP（…）"）。按设计 §5.5 判据，它们**是文案**，必须改成 `Text("发行方：\(x)")` 并出译文；保持 verbatim 则 en 界面必现中文。→ TC-04（并把该结论回流 lead，见 §14 C-1）。
3. **`NSMenuItem(title:)` 等 AppKit 面不经 Text 查表**：`Platform/StatusItemController.swift` 的菜单项即使 666 处 Text 全绿也不会翻。→ TC-09。

> 结论：**「666 处 Text 零改动」不等于「英文界面干净」**。G1 族的判定顺序是「静态值无 CJK（INV-L2）→ 静态键覆盖 → 表达式/verbatim/AppKit 三类偏移面闭合 → 运行时 AX 五面扫描」，四层互不替代。

### 1.3 反向先红（防恒绿断言）

- **TC-02（键覆盖）**：证明它能红的方式不是等它红，而是注入 #2 后**必须红**；若删一条译文仍绿，说明它统计的是「文件行数」而不是集合差。
- **TC-13（既有单测全绿）**：恒绿风险最高（`failed == 0` 天然为真）。反向核销 = 临时把某个断言改成 `check(false, ...)` → 必须红 → 回滚。**没有这一步，TC-13 不能记绿。**
- **TC-39（签名校验）**：注入 #6 后必须红；本机若 `codesign --verify --strict` 对**任意**改动都返回 0（例如身份缺失时脚本提前退出），则该用例无效，必须改为「断言 `build exit=0` 且产物哈希变化」。

## §2 判据锚点与可测性前提

### 2.1 锚点纪律

- 以**文件 + 符号名 + 键/文案原文**锚，**不写行号**（行号随实现漂移；§1.1 里的行号仅作 2026-10-24 定位快照，核销时用 `grep -n` 重新定位）。
- 新符号（`LanguagePreference` / `CoreErrorText` / `check_l10n.sh` 的 check 名）是**测试侧期望的调用面**；dev 若采用不同命名，**只更新锚点、判据不变**，并在修订记录登记。

### 2.2 可测性前提（判据成立的条件；不满足则对应用例降级为「未覆盖」，不得以「代码看起来对」代替）

| ID | 前提 | 不满足时的处置 |
|---|---|---|
| TP-1 | `LanguagePreference` 的读写**可注入 appID / 偏好域**（默认 `Bundle.main.bundleIdentifier`），且 `apply()` 返回「是否需要重启」 | 23–31 在 standalone 单测里会把值写进测试二进制自身的域（或 nil 崩溃）→ 降级为仅 AX 真机核销 |
| TP-2 | `tools/check_l10n.sh` 支持**资源根 / 源码根 / 清单文件覆盖**（实测 2026-10-24：env `L10N_LOCALIZATION_DIR` / `L10N_SOURCE_DIR` / `L10N_ALLOW_FILE` / `L10N_EXCEPTIONS_FILE`，另有 `--resources-only` 只跑 G1–G4），可在 `/tmp` 副本上跑 | 53–64 的负例注入只能改真源 → 违反测试隔离（禁区）。**当前实现已满足**（观察到 env 覆盖 + `--resources-only`），核销时复验一次 |
| TP-3 | 源码字面量抽取输出**机器可读清单**（TSV/JSON：文件、字面量、推导键、插值类型、是否例外） | 02/03/04 退化为人工逐条读 → 明确登记「未覆盖（无机器读数）」 |
| TP-4 | `CoreErrorText.text(forCode:)` **零 CoreBindings 依赖的纯函数**（与 `LicenseError` 同型） | 44–52 无法单测（需链接 FFI 静态库）→ 降级走查 |

| TP-6 | 能构造**最小 fixture .app bundle**（`Info.plist` + `en.lproj/Localizable.strings`）并可被探针进程以指定语言解析 | 17–20 无法做受控回退实验；**不得**用真实 en 表冒充（真实表补全后缺键用例即失效，见 §1.2 #12） |

## §3 G1 —— en 环境全量界面无中文残留（10 条）

> **组前置 P-G1**：① 存在构建产物 `macos/build/Coffer.app`（含 `en.lproj`，签名校验通过）；② `en/` 五个分片 + `Localization/InfoPlist.strings` 已入库；③ 语言切 en 的手段已按 TP-7 定死；④ 夹具数据**全英文**（库名 `TestVault`、条目名 `Sample Item`、文件名 `report.pdf`）——中文夹具会让 AX 扫描误报，见 §16 未覆盖 1。
> **共用判据**：CJK 正则 = `[\u3400-\u4dbf\u4e00-\u9fff\uf900-\ufaff]`（含扩展 A / 兼容区）；命中必须**打印命中文本 + 来源元素**，不接受「大概没有」。

| 用例 | 名称 | 前置 | 步骤 | 预期 | 判据（机器可判定） | 分级 | 状态 |
