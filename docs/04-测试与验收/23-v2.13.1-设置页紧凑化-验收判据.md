## §0 范围与不变量

**本版一行意图**：把设置页的**留白结构**收紧密（左右外边距 20→12、行高 44 / 37.5→36 / 32、卡距 10→8、页顶底 20→12），窗宽 480→460 以保住文本区 420pt 不变。**字号、文案、控件、交互一律不动。**

**非目标（判据不得据此判红）**：

- 不改任何字号 / 字体 token（D-11.6）；不改任何文案字面量（零新增文案，l10n 门禁不受影响）。
- 不改 5 个设置页 sheet 的宽度（许可 / 从备份恢复 / 管理密码库 / 跨库复制 / 生成器默认参数 仍 480；统一宽度是另一个任务）。
- 不新增 / 删除 / 重排任何设置控件、不改任何交互行为（含三态节状态机、MCP provider 分支）。
- 不追求「整体紧凑感」的机器判定（设计 §5.2-6：唯一只能截图评审项）。

**必须保持不变的不变量（任一被破坏即判红，即使数值全部达标）**：

**自动化分层沿用 `docs/04-测试与验收/19-UI测试自动化分层设计.md`**：本文「探针」= L2 形态（真视图 + 合成夹具，任何环境可跑，可进 CI）；本文「AX」= L3（恒 local，需 GUI + TCC）。**载体列取值**：`PROBE` / `AX` / `STATIC` / `MANUAL`。

**几何取值纪律（适用于全部 AX 几何用例）**：

1. 坐标用 AX 屏幕坐标，但比较用**相对量**（同一窗口内两元素之差），不用绝对值——窗口位置可被用户拖动。
2. 三级取法：卡片 x 取 AXGroup；行 inset = 行内首个交互控件 x − 卡片 x；行高优先取行容器 h，否则取「相邻两行首个交互控件 y 差」。
3. 每项测 3 次取中位数；极差 > 1pt 判 flaky 并重取（窗口动画未收敛）。
4. 容差：几何量 ±0.5pt；圆角 ±1pt。

| TC-SET-63 | 滚到顶不透标题栏（INV-SET-6） | `scrolltop` → 截图 + `geom` 取首节页头「通用」的 y | 页头完整可见，不与标题栏重叠；标题栏区域无滚动内容墨迹 | `header.y >= contentTop - 0.5`（contentTop = 标题栏下缘）；截图人工复核标题栏不透明 | AX + MANUAL |
| TC-SET-64 | 往返滚动后清单仍全 | 顶 → 底 → 顶 各一次，最后抓全树 | 与初始集合相等 | `set_after == set_initial`（防滚动触发的 onAppear / onDisappear 副作用丢控件） | AX |

## §9 G 组 —— ⑦ Dynamic Type 放大不裁切不重叠（6 条）

> **组前置 P-G**：① 探针 harness（TP-SET-3）；② 含 `@ScaledMetric` 的度量（如 `McpAgentToolsSection` 的 `iconSlotWidth`，现状已是 `@ScaledMetric(relativeTo: .callout)`）必须随字号放大，不得改回常量；③ **macOS 无 iOS 式系统 Dynamic Type 开关**（仓内零 `dynamicTypeSize` 命中），故本组**只在探针里注入 `.environment(.dynamicTypeSize, …)`**，真机档不可达（§12 C-3）；④ 探针必须渲染**真实 `SettingsRow` / `SettingsCard`** 而非裸 `Text`，否则测不到行高语义。

| ID | 用例 | 步骤 | 预期 | 判据（机器可判） | 载体 |
|---|---|---|---|---|---|
| TC-SET-70 | accessibility3：行高 ≥ 内容高 | 注入 `.dynamicTypeSize(.accessibility3)` 渲染单行 / 动作行 / 双行三种行 | 行高随内容增高，内容不越界 | `row.h >= content.h` 且 `content.y >= row.y - 0.5` 且 `content.y + content.h <= row.y + row.h + 0.5` | PROBE |
| TC-SET-71 | accessibility3：相邻行不重叠 | 同上，取相邻行区间 | 无交叠 | `rowA.y + rowA.h <= rowB.y + 0.5`；且行间分隔线仍在两行之间（不压字） | PROBE |
| TC-SET-72 | accessibility5（最大档）：不裁切 | 注入 `.accessibility5` 重跑 70 | 同 70 | 同 70。**反向核销**：`minHeight` 改成 `.frame(height: 32)` 定高时必须红（§1.2 #7） | PROBE |
| TC-SET-73 | accessibility5：长文案换行而非截断 | 最大档下渲染 en MCP 页脚段落 | inkLines == needLines（按放大后字体量测） | `inkLines == needLines` 且 `inkLines > 1`（放大后必然多行；退化为 1 行说明量测取错字体） | PROBE |
| TC-SET-74 | accessibility3 / 5：外边距与卡宽不破 | 同两档下取卡片 x / w | 仍 12 / 436 | `card.x == 12 ± 0.5` 且 `card.w == 436 ± 0.5`（字号放大不得撑破卡片外边距——撑破说明用了 fixedSize 或宽度写死） | PROBE |
| TC-SET-75 | 无定高写法（INV-SET-4） | 静态：`SettingsStyle.swift` 内 `frame(height:` 命中数；探针：最大档下行高 > 普通档行高 | 静态 0 命中；探针行高随字号严格增大 | `grep -c 'frame(height:' SettingsStyle.swift == 0` **且** `row_h(.accessibility5) > row_h(.large)`（严格 >，相等 = 定高） | STATIC + PROBE |
