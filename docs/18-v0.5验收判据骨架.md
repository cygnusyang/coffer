## 2. 负路径与边界清单（r1.2 按降级形态修订；方向级 + 已落定接口面）

- **rpId 边界（r1.2 落定）**：rpId 非法 → 1012；`rp_id_hmac` 写入保留但**查询面本版不暴露**——「FFI 无 by-rp 查询方法」为结构断言（TCB-7）；完整版 ADP 重启前该索引无消费方。
- **删除反面**（FR-10.5 反面）：删除失败路径不残留半状态；passkeys 纯 DB 行无旁路文件（与附件面对照，无「先删行后删文件」问题面）。

3. **禁止指向 App 沙盒真实库路径**（`14` §5 明令不回退）；临时库 + 合成 fixtures（Bitwarden JSON 四类：含密码+passkey / 纯密码 / 非 ES256 / 坏 passkey 行）。

5. **计数口径**：引用门禁读数声明 `filtered` ≠ `failed`；`--ignored` 须配 `--all-targets`；门禁在 `core/` 下跑。
6. **真实网站项不 mock、不 fixture 化**（r1.1 吸收，**随分支 A 休眠**）：唤醒完整版时恢复——本地/离线 passkey 测试服务不得替代验收网站数。
7. **真实凭据不进仓库**（r1.1 吸收，降级版继续适用）：逆向核对产生的真实 passkey 私钥/网站凭据一律不进 fixture 与仓库；自动化 fixture 用合成 passkey 数据（PKCS#8 编码形态已由 `17` §3.1 裁定，待用户确认后落定）。
