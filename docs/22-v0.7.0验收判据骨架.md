### 0.2 本版门禁断言总则（映射 `03` §14.6 矩阵）

本版新增两条写路径，必须纳入只读许可门禁矩阵：

| 新路径 | FFI/会话方法（暂定，待设计定稿） | 门禁组（`03` §14.6） | 只读态拒绝码 |
| --- | --- | --- | --- |
| 1PUX 导出 | `export_1pux` / `export_one_pux`（镜像 `export_csv`，cf-session `write_guard` 收口） | **ExportData**（数据出口，FR-15.2 明确全拒） | 6002（到期）/ 6003（异常退化） |

> 判定语义对齐 `03` §14.6：拒绝发生在写事务之前、不落任何半截数据（TC-GATE-08 同款纪律）；错误码区分 6002/6003 属 UX 引导需要（§14.5），不可合并。新方法经 `write_guard` 单点收口即满足「新增写用例必过门禁」的结构性保证（TC-GATE-12，docs/12）。

## 2. 负路径与边界清单（方向级 + 已落定面）

- **导出反面（FR-8.2）**：只读态拒绝（6002/6003）且不产生输出文件（TC-EXP-06）；锁定 1001；路径不可写 2003；导出无源库副作用（TC-EXP-09）。**明文面纪律**：1PUX 为明文导出，二次确认 UI 门禁不可绕过（FR-8.4 精神，TC-EXP-12）。
- **导出边界**：空库 / 超长 Unicode / 大附件 / passkey 条目不随 1PUX 导出（明示边界）。
- **导入反面（FR-7.3）**：错误主密码 all-or-nothing 不导入；损坏/篡改 opdata 不落明文；格式不识别 2001；只读态拒绝 6002/6003 不落半截数据（TC-OPV-05）；锁定 1001。
- **导入边界**：Tombstone 跳过；未知分类码不静默丢弃；DoS 上限（≤ 10 000 items）；空库；`trashed` 归档态。
- **大字号反面（FR-12.4）**：锁定联动关闭不残留明文；无显式入口不得弹出；超长/Unicode 不截断不溢出。
- **设置项反面（FR-14.3~14.5）**：非法生成器参数不保存；诊断面结构性不含敏感数据（白名单断言）；自证声明与事实一致（不夸大）；零网络不回退（静态 + 运行时 0 socket + 阳性对照）。
- **QR 反面（FR-5.3）**：非 TOTP 内容不误判；畸形 URI 明确拒绝；相机权限拒绝优雅降级。
- **BUG-11 反面**：错误导出密码不落半截数据；EncString 缓解不回归（bad_passkeys 逐条列出、不静默丢弃）。
- **门禁纪律**：沿用 `16` §1 判据⑥反面全套（`--no-fail-fast`、`core/` 下跑、管道退出码 `${pipestatus[1]}`、沙盒路径禁令）。
