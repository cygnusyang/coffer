### 1.2 FR-7.3 opvault 导入（TC-OPV，新写路径，门禁 ImportRestore）

> 判据基准：`22` §2.2（**r1.3**：D-04 已闭环 `docs/24`，150424b）+ §3.2 冻结签名。密码学链复用 `03` §6.3（PBKDF2-HMAC-SHA512 → masterKey/overviewKey → item keys；Encrypt-then-MAC，AES-256-CBC + HMAC-SHA256）。**双解码路径（核心 r1.3 修正）**：item keys `k` **无头** `[IV:16]‖[ct]‖[MAC:32]`；opdata01（`d`/`o`/masterKey/overviewKey）**带头** `[magic "opdata01":8]‖[plen:8 LE]‖[IV:16]‖[ct]‖[MAC:32]` + **前置随机填充取末 plen**（CBC 填充非 PKCS#7，规避 padding-oracle）；**跳过条目级 `hmac` 字段校验**（第三方实现覆盖范围有分歧，以各 opdata MAC 为唯一完整性防线）；密码 UTF-8 原始字节进 PBKDF2，**勿追加 NUL**（§2.2.1）。D-04 交叉验证不再为 `T02` 任务项。
