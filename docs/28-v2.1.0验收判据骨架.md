## §0 范围与总开关

- **本版定位**：v2.1.0 = 用户 2026-10-07 追认生成的四个工作项（docs/27 汇总行 + v2.1.0 工作项）：
  ① **D-2 翻转缺省 provider**（coffer 转正，op 降可选）；② **MEDIUM-2 生产级随机轮换**（Coffer 生成器强随机值作轮换新值）；
  ③ **L-5 审计日志 subscriber**（既有顺延，v2.1.0 落位）；④ **UDS 传输实现**（D-4，docs/20 §3.1/§3.6）。
- **出口判据**：
  1. **D-2 翻转**：缺省 provider = coffer（无 flag / 无 env）；coffer-store 转 default feature（`--no-default-features` 才瘦依赖树）；feature 关闭时缺省 coffer 不可用 → **回落 op（带告警日志），op 亦不可用 → 7001 退出 1**，显式 coffer → unsupported 退出 1（D-1 退出码契约不破坏）；**D-1 冻结面零改动**（4 工具名/参数/返回、CLI flag、退出码 0/1/2/3、7xxx 表，逐项对照 docs/27 D-1 附文）；op 可选路径回归不破（§1.1 + §3.1）；
  2. **MEDIUM-2**：rotate 新值不可预测（时间戳格式不再出现）+ 生成器默认强度 + 旧值失效 + 轮换戳/审计打点不回归；**变异探针预案**（改回时间戳实现须转红，§1.2 + §2）；
  3. **L-5**：审计失败 warn 进入诊断通道可观察（stderr / `--log`）；不引入新依赖（§1.3 + §2）；
  4. **UDS 传输**：docs/20 §3.1/§3.6 规格逐条判据（监听/权限/getpeereid/challenge/单调 id/退出码复用），**🔴 依赖 TB 实现，验收排后**（§1.4，先列骨架不封口）。
- **总开关**：§1~§3 判据全部通过 = 本版 PASS；D-1 冻结面零改动为最高优先（全量门禁回归全绿为前提）；UDS 验收在 TB 实现落地后按 §1.4 逐条补测（不阻塞其余三项核销）。

> **零网络语义**：本文引用「零网络 / 不联网」一律按 docs/27 D-4 新口径——**禁止外部网络（不去云端、数据不出本机）为硬承诺；本机内通信（UDS / 本机回环）允许且不违背该承诺**。措辞改写工单（docs/27 附表）随 UDS 实现同步验收。
