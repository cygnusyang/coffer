## §0 范围与总开关

- **本版定位**：v2.1.0 = 用户 2026-10-07 追认生成的四个工作项（docs/27 汇总行 + v2.1.0 工作项）：
  ① **D-2 翻转缺省 provider**（coffer 转正，op 降可选）；② **MEDIUM-2 生产级随机轮换**（Coffer 生成器强随机值作轮换新值）；
  ③ **L-5 审计日志 subscriber**（既有顺延，v2.1.0 落位）；④ **UDS 传输实现**（D-4，docs/20 §3.1/§3.6）。
- **出口判据**：
  1. **D-2 翻转**：缺省 provider = coffer（无 flag / 无 env）；coffer-store 转 default feature（`--no-default-features` 才瘦依赖树）；feature 关闭时缺省行为不破坏 D-1 退出码契约；**D-1 冻结面零改动**（4 工具名/参数/返回、CLI flag、退出码 0/1/2/3、7xxx 表，逐项对照 docs/27 D-1 附文）；op 可选路径回归不破（§1.1 + §3.1）；
  2. **MEDIUM-2**：rotate 新值不可预测（时间戳格式不再出现）+ 生成器默认强度 + 旧值失效 + 轮换戳/审计打点不回归；**变异探针预案**（改回时间戳实现须转红，§1.2 + §2）；
  3. **L-5**：审计失败 warn 进入诊断通道可观察（stderr / `--log`）；不引入新依赖（§1.3 + §2）；
  4. **UDS 传输**：docs/20 §3.1/§3.6 规格逐条判据（监听/权限/getpeereid/challenge/单调 id/退出码复用），**🔴 依赖 TB 实现，验收排后**（§1.4，先列骨架不封口）。
- **总开关**：§1~§3 判据全部通过 = 本版 PASS；D-1 冻结面零改动为最高优先（全量门禁回归全绿为前提）；UDS 验收在 TB 实现落地后按 §1.4 逐条补测（不阻塞其余三项核销）。

> **零网络语义**：本文引用「零网络 / 不联网」一律按 docs/27 D-4 新口径——**禁止外部网络（不去云端、数据不出本机）为硬承诺；本机内通信（UDS / 本机回环）允许且不违背该承诺**。措辞改写工单（docs/27 附表）随 UDS 实现同步验收。

### §1.2 MEDIUM-2 随机轮换（docs/27 MEDIUM-2）

> 现实现（lib.rs `rotate_secret`）：写 `rotated-{nonce}`（`as_nanos` 时间戳，可预测）。用户裁定选 B：v2.1.0 接生产级随机源（Coffer 生成器强随机值 = `cf_audit::generate_password(PasswordGenOptions::default())`，CSPRNG 20 位四类字符，cf-audit/lib.rs:86-98 默认策略）。

| 判据 | 现有测试 / 需新增 | 状态 |
|---|---|---|
| **rotate 后新值不可预测**：不出现时间戳格式（`rotated-\d+` 或纯递增数字串）；两次 rotate 值不同且无明显可预测关联 | 现 `rotate_secret_changes_value`（仅 before≠after，时间戳实现也能过）——**需新增强度断言**：新值不得匹配 `rotated-\d+` 时间戳形态 + 连续两次 rotate 值不同 | 🔴 新增 |
| **新值满足生成器默认强度**：长度 ≥ 20、四类字符齐全（数字/小写/大写/符号）、排除易混淆字符（`iI1loO0"'`|`） | 新增断言（按 `PasswordGenOptions::default` 语义逐项核对，cf-audit/lib.rs:88-97） | 🔴 新增 |
| **旧值失效**：rotate 后旧值不再可用（注入面读到新值，旧值不可注入） | `rotate_secret_changes_value` 扩展：after 为新值且 ≠ 旧值（已覆盖 before≠after）+ 可加「旧值不出现」断言 | 🟡 扩展 |
| **轮换戳不回归**：rotate 后 `last_rotated_at` 非空（AS-9） | `rotate_secret_updates_metadata`（v2.0.0 已加固为断言非空，e351e10）——保持不变回归 | ✅ 回归 |
| **审计打点不回归**：rotate 后 audit 调用不炸 | `audit_secret_usage_ok_after_use_and_rotate` 回归 | ✅ 回归 |
| **变异探针预案**：改回时间戳实现（`rotated-{nonce}`）→ 强度断言测试须**转红**；改回复绿。探针不提交 | 验收时执行（先红后绿；强度断言须对时间戳实现敏感） | 🔴 探针预案 |
