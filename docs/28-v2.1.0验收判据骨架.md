- **本版定位**：v2.1.0 = 用户 2026-10-07 追认生成的四个工作项（docs/27 汇总行 + v2.1.0 工作项）：

  3. **L-5**：审计失败 warn 进入诊断通道可观察（stderr / `--log`）；不引入新依赖（§1.3 + §2）；
  4. **UDS 传输**：docs/20 §3.1/§3.6 规格逐条判据（监听/权限/peer 凭据/challenge/单调 id/退出码复用）——**✅ 已实现（dev-coder-qr 7f3ec7b/7cb62c7）并验收核销**（§1.4）。
