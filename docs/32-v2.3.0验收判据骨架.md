## §0 范围与总开关

- **本版定位**：v2.3.0 = 浏览器扩展（WebExtension + native messaging），docs/31 §0 结论先行 + §9 任务分解：
  - **8 项架构裁定**（docs/31a D-1~D-7）：D-1 通道认证四层叠加、D-2 宿主进程模型（复用嵌套 bundle coffer 二进制，browser-agent/browser-broker 两子命令）、D-3 origin 绑定三型冻结、D-4 manifest 冻结点、D-5 Safari 顺延二期、D-6 通道机密性（P-256/AES-GCM E2E）、D-7 捕获触发面（submit+验证）。
  - **并行分组**（§9.1）：Wave-1 G-A∥G-C∥G-D∥G-F（文件互斥）→ Wave-2 G-B（依赖 G-A + P-S）→ Wave-3 G-E（依赖 G-B）→ Wave-4 G-T（本判据核销）+ G-R（reviewer 安全门禁）。
- **必须落档的语义（docs/31 硬约束，判据不依赖设计细节的命名，只断言行为）**：
  - **扩展零库密钥**（DEK/KEK/mcp_key/子密钥一律不进扩展）；传输层材料（会话密钥/配对 PSK/broker 公钥）属扩展持有边界——两者在文档与代码中显式区分（docs/31 §3.3）。
  - **解密全在 broker**，通道按需传解密值；host（browser-agent）零授权零解密零持久态（薄中继）。
  - **填充必须显式用户手势**（DEF CON 33 点击劫持）：手势令牌单次 + TTL 30 s + 绑定 UI 事件；不自动填、不预填。

  - **v2.2.0 权威基线（docs/30 r0.6 终门禁定谳）**：`cargo test --workspace --no-fail-fast -- --skip 极端kdf参数建库记录与解锁往返 --skip 千条搜索基线`（core/ 下，无管道，日志落盘逐段求和）= **1172 passed / 0 failed / 9 ignored**（93 test binary，exit 0，skip 2 条已声明；lead 两次独立复现一致）。配套：cf-mcp no-default **206/0**、mcp_acceptance default **42** / no-default **41**（1 门控）、clippy 双配置 0 告警、check_no_network **182 deps / 0 黑名单 / PASS**、McpStatusTests **59/59**。

1. **browser 子命令与 feature 门控（待 G-B/G-E 定）**——cf-browser 依赖 cf-session/cf-crypto（仅 default `coffer-store` feature 引入，`core/cf-mcp/Cargo.toml`）。`--no-default-features` slim 构建下 `browser-agent`/`browser-broker` 子命令如何处置？建议：子命令随 default feature 门控（slim 构建不注册或 graceful unsupported，不破坏退出码契约）。§5-2 的 no-default ≥ 206/0 面依赖此定夺。**判据 §1.2-6 退出码契约须覆盖该门控语义**。
   - **已裁决（lead 2026-10-07）**：browser-* 子命令 gating = **复用既有 `coffer-store` feature，不新增 `browser` feature**。cf-mcp Cargo.toml 增 `cf-browser = { path = "../cf-browser", optional = true }` 并入 `coffer-store = ["dep:cf-session", …, "dep:cf-browser"]`；cli.rs browser-* arm 用 `#[cfg(feature = "coffer-store")]` 门控，slim build 不注册 → 走既有 unknown-subcommand 分支（cli.rs:617）fail-closed。影响：no-default 206/0 门禁面不变（slim 不拉 p256/aes-gcm）；cf-browser 纯 lib 无 feature、两构建面测试均跑（计数只增不减）；check_no_network 仅 default 面重标（G-E 负责，p256/aes-gcm vendored 无网络）。**§1.2-7 判据按此落锁**（slim build 门控 fail-closed 自动核销）；§1.2-6 退出码契约覆盖该门控语义；docs/31 §9.1 G-B「P-S gate」不变。
2. **cf-browser 依赖方向复核**——docs/31 §2.2 冻结：cf-browser → cf-domain/cf-crypto/cf-session（单向），不得被 cf-session/cf-store/cf-ffi/cf-domain 反向引用；cf-mcp 仅作组合根。G-A 实现须验证依赖边（cargo tree / 编译期守卫）。
