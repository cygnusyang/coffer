环形钥匙 · 比例重画

v2 的钥匙四个毛病：环孔太小、柄短而粗、齿不成结构、整体占比偏小。v3 按真实钥匙的比例关系重建，数据在右侧。点大图旁的「比例辅助线」可看构造。

比例关系（100 × 100 视图）

钥匙的可读性来自四个数的平衡，其余都是装饰。

环外径Ø36柄宽的 3.8 倍——环是主角
环孔Ø24.5占环外径 68%——v2 只有 48%，所以像实心圈
柄长46略长于环直径，出头才有「钥匙」的动感
齿12.5 / 9.5 × 9两齿一宽一窄贴柄末，v2 的齿浮在柄中部像补丁
画布占比≈81%对角线展开后 v2 只有约 66%，缩在中间显小

Icon Composer 分层说明

background layer : 线性渐变 #57A0FF → #5F6CF8 → #A13EF2（150°）+ 左上光晕，1024×1024 满幅不透明
foreground L1 : 环 + 柄 + 宽齿（不透明，白色玻璃渐变填充）
foreground L2 : 窄齿（opacity 62%，比 L1 低一档深度，系统折射会做出前后景深）
禁止 : 自带圆角遮罩 / 自带投影 / 自带高光 —— 全部由系统 Liquid Glass 渲染
