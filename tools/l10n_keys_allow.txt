# l10n_keys_allow.txt —— 多语言键允许清单（v2.13.0，设计 24 §4.5 G5）。
#
# 一行一个键（中文原文，不带引号），# 开头为注释，只支持整行注释。
# 这里的键有两个作用，都指向同一件事：把「已知的例外」与「还没做的缺口」分开。
#
#   1) G5 死键校验（硬）：清单里声明的键必须仍能在源码中找到出处，且必须在 en
#      译表里。文案改了、控件删了而清单没清 → 「死键」硬失败——否则豁免会越积
#      越多，最后没人敢删（设计 §4.5 G5 的失败后果）。
#   2) G6 覆盖率（软）：清单里的键不计入「未翻译清单」的分母，避免报表被已知
#      不可翻项长期污染（设计 §5.2 例外清单制度的对偶）。
#
# 什么该进这里：**无法翻译**的裸中文残留（用户数据被误当期文案、纯符号、非语言
# 内容如路径/命令串）。**能翻但还没翻**的不要进这里——那是 G6 的缺口，进清单
# 等于把缺口藏起来。
#
# 格式示例（取消行首 # 即可生效）：
#   回收站
#
# 当前为空：v2.13.0 infra 落地时尚无已确认的不可翻项；三组实现期发现后按上面
# 的判据逐条追加，并在提交信息里写明理由。
